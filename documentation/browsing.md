# Browsing datasets (web app)

Open <https://blackpearl006.github.io/NeuroDataHub/>.

The web app has:

- a grid view and a table view
- a search box for dataset names
- a pathology filter (for example Alzheimer's, Autism, Schizophrenia)
- an age range slider
- a detail window for each dataset, with age and sex distribution charts and links to the source and papers
