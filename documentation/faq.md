# FAQ and troubleshooting

## Does NeuroDataHub host the data?

No. Downloads come from the original source.

## A download fails with a missing dependency

Run `neurodatahub check`. It lists the missing tools and how to install them.

## A dataset needs a login

Some datasets need an account or a data use agreement. The CLI shows the steps.

## I can see a dataset in the web app but not in the CLI

The CLI supports a subset of the datasets in the web app.
