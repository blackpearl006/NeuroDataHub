NeuroDataHub

NeuroDataHub is an open-access platform designed to help you explore, compare, and analyze neuroimaging datasets with ease. Whether you're a researcher, clinician, or student in neuroscience or AI, this site brings together an extensive collection of 50 carefully curated public datasets, totaling over 50,000 brain scans.

Each dataset is accompanied by an accessible overview and a summary of potential research directions

Discover the data that fits your project, and accelerate your research.

🧠 Explore Brain Datasets

Access 50 open neuroimaging datasets covering over 50,000 brain scans, including structural MRI, functional MRI, and diffusion imaging. Quickly compare datasets, understand their formats, and discover how to use them in real research.

👨‍🔬 For Research & Learning

Built for students, clinicians, and researchers, this platform offers a beginner-friendly guide to each dataset along with ideas for machine learning, neuroscience, and medical imaging applications — no clutter, just insight.

📊 Stats, Scans & Links

Get insghts of key statistics (like scan counts, modalities, age ranges), and papers using each dataset. Save hours of search time — everything you need is neatly organized in one place.

NeuroDataHub CLI

A powerful command-line interface for downloading neuroimaging datasets with ease!

🚀 Access 30+ Neuroimaging Datasets from Your Terminal

NeuroDataHub CLI brings the power of our curated dataset collection to your command line. Download popular neuroimaging datasets from INDI, OpenNeuro, ReproBrainChart, and more with simple commands.

Terminal
$ pip install neurodatahub-cli
$ neurodatahub --list
📊 Available Datasets (30+)
$ neurodatahub pull HBN ./data/HBN
🚀 Downloading HBN dataset...

✨ Key Features

🗂️

30+ Datasets

Access popular neuroimaging datasets from multiple sources including INDI, OpenNeuro, and ReproBrainChart

🔍

Smart Search

Find datasets by name, description, category, or research focus with powerful filtering

🚀

Multiple Backends

Supports AWS CLI, aria2c, DataLad, and more for optimal download performance

🔐

Authentication Support

Handles various authentication workflows including interactive IDA-LONI processes

📊

Rich UI

Beautiful tables, progress bars, and interactive prompts for enhanced user experience

⚡

Resume Support

Interrupted downloads can be resumed, saving time and bandwidth

🔧 Quick Installation

Via pip

pip install neurodatahub-cli

Via conda

conda install -c conda-forge neurodatahub-cli

💻 Common Commands

📋 List & Search

neurodatahub --list
List all available datasets
neurodatahub search "brain development"
Search for specific datasets

📥 Download

neurodatahub pull HBN --path ./data/HBN
Download a dataset to specified path
neurodatahub info HBN
Get detailed dataset information

🔧 System

neurodatahub check
Check system dependencies
neurodatahub --help
Show help and all available commands

📂 Supported Dataset Categories

INDI Datasets

No Authentication Required

  • HBN - Healthy Brain Network (2TB)
  • CORR - Consortium for Reliability (500GB)
  • ADHD200 - ADHD diagnosis (200GB)
  • NKI - Nathan Kline Institute (800GB)

OpenNeuro

Open Platform Datasets

  • AOMIC - Amsterdam Open MRI Collection
  • Pixar - fMRI responses to movie clips
  • MPI - Max Planck Institute datasets
  • Dense sampling - High-resolution subjects

Independent

Direct Access Datasets

  • IXI - Imperial College brain MRI (12GB)
  • OASIS-1/2 - Aging studies
  • HCP - Human Connectome Project*
  • CamCAN - Cambridge aging study*
* Requires authentication

IDA-LONI

Interactive Authentication

  • ADNI - Alzheimer's Disease Initiative
  • PPMI - Parkinson's Progression Markers
  • AIBL - Australian Imaging Biomarkers
  • MCSA - Mayo Clinic Study of Aging
